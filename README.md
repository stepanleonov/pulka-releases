# Пулька — выпуски

Здесь лежат готовые сборки игры «Пулька» (преферанс для Windows) и файл `latest.json`,
по которому игра сама узнаёт о новой версии.

- **Pulka-Setup-<версия>.exe** — установщик: лицензия, выбор папки, значок на рабочем столе и в меню «Пуск».
- **Pulka-<версия>-windows.zip** — без установки: распаковать и запустить `Pulka.exe`.

Windows может показать «Защитник Windows предотвратил запуск» (программа не подписана):
нажмите «Подробнее» → «Выполнить в любом случае».

Если игра уже установлена, обновиться можно прямо из неё: в главном меню появится
кнопка «Доступна версия … — Обновить». Настройки, профили и партия при обновлении сохраняются.
